# How to retrieve files later

Start with the [current recovery index and kit](https://github.com/raaaaaif/frameo-free-recovery-20261029). The running backup job updates that GitHub page after each successful batch. This Page and its attached files are a dated snapshot. Open the recovery links below to browse or download saved files. The small recovery kit at the end contains a QUICKSTART guide, file lists, checksums and an optional downloader; it does not contain the large payloads. When you have an external drive, extract the kit there and follow its guide. The downloader lists plans by default and requires an explicit destination before downloading. GenBio is private: sign into your hellnahbru Hugging Face account. New source copies appear in [your GitHub repositories](https://github.com/raaaaaif?tab=repositories). Software Heritage bundles can be regenerated from the directory IDs recorded in the manifest if a cached export expires.

11 original model repositories have new copies under your account. The 16.1 TB arXiv mirror is an existing copy under another account. All model download checks use only tiny samples for large files; they do not constitute a full multi-terabyte rehash.

Full source verification means the complete compressed archive was read, its checksum was checked, and its source tree was matched to the pinned commit. Model verification means all listed hashes/sizes match, small files were fully hashed, and samples from large files downloaded successfully. Separate Hugging Face repositories protect against original-repository deletion, but not platform-wide loss. No third-party service guarantees permanent availability.

This is an existing historical archive, not the full current PMC collection. [Europe PMC](https://europepmc.org/) supplies additional, independently hosted articles: [XML archives](https://ftp.ebi.ac.uk/pub/databases/pmc/oa/) and [PDF packages](https://ftp.ebi.ac.uk/pub/databases/pmc/pdf/OA/). All 1,314 XML archives passed bounded retrieval and gzip-header checks; one XML archive, one PDF package and one full article passed complete reads. Coverage differs from NLM. A separate [June 2025 PMC torrent](https://github.com/raaaaaif/frameo-free-recovery-20261029/blob/main/PMC-June-2025.torrent) contains 1,744 XML/text data files and file lists totaling 343.001 GB, plus 82 padding entries (347.357 GB total torrent size). PDF and image packages are not included. A complete 1.835 MB piece passed its published SHA1, and the serving peer advertised every piece. The entire collection was not downloaded; this route depends on peers remaining online. The tiny torrent file is preserved in the recovery kit with instructions for downloading later directly to an external drive using free Transmission. It is a historical snapshot, not the complete current collection. See the [Europe PMC bulk documentation](https://dev.europepmc.org/downloads/openaccess).
